In one sentence

On routable forward questions, matching adapters moved answer accuracy from about 43% to 53%; self-routed VAMP reached about 52% and selected the named world about 77% of the time.

—
How the experiment works

The goal is simple: separate ordinary word familiarity from knowledge of a specific fact. The base model can see the word “cat,” but it cannot see registered stories saying, for example, that cats have fur.

1Review facts

Twelve human-reviewed facts for each of five worlds.

2Withhold them

Every story expressing one of those facts is removed from base training.

3Train adapters

Small rank-eight LoRAs read the fact-bearing stories; word embeddings stay frozen.

4Freeze choices

Model settings and routing keys are fixed using validation questions only.

5Keep routable questions

Three unseen forward phrasings per fact; every prompt names its world.

What counts as success? The model scores four answer choices. Only the answer words count—not the wording of the question. Random guessing would average 25 correct answers out of 100.
Post-result disclosure: the registered 300-question result remains immutable. After we found that some reverse prompts did not identify a unique world, this derived view excluded all 120 reverse questions by one uniform rule. It is an honest directional diagnostic, not a replacement preregistered result, and it was not used to tune any model.

What happened

Among the questions that name their world, the base answered 42.8% correctly. Matching independent LoRAs reached 53.3%, VAMP with the right node supplied reached 52.8%, and VAMP choosing its own node reached 51.7%.

Random four-choice guessing: 25%

What does “points” mean? It is the direct gap between two percentages. Moving from 42.8% correct to 53.3% correct is a gain of 10.6 percentage points. That is different from saying accuracy grew by 10.6 percent.

Method guide and caveats

These labels are easy to blur together. This guide separates “what knowledge exists” from “how the system decides where to look.”

What this result does—and does not—show

  • It shows that, on forward questions naming their world, small LoRA adapters improve direct answer ranking for deliberately withheld facts by 10.6 points, with a fact-resampled 95% interval from 3.3 to 17.8 points.
  • It shows that the EBT router selected the named world 77.2% of the time and answered 51.7% correctly, compared with 52.8% when the correct node was supplied.
  • It excludes reverse questions because some of them do not uniquely identify a world; it makes no claim about solving that ambiguous routing task.
  • It is a post-result directional analysis. The original full test, including its reverse questions, remains the registered primary result.
  • It is one seed, one architecture, five reviewed concept families, and a descriptive result—not a universal pass/fail claim.
